# Roleplaying Adventure
A narrative driven interactive roleplaying game built in streamlit. Feautures a BTS logic trial, and Valorant characters!

# What I did
I build a multi scene interactive game using Python and Streamlit
Structured game progression using pandas dataframes at 'st.session_state' to track scenes and player choices.
Made an inventory tracking system
Input a 5 question logic quiz that resets after getting something wrong and a button smashing game to free Sage.

# What I learned
How to keep data persistent even during browser reruns in streamlit using session_state
How to maniuplate Python dictionaries and convert them into Pandas Dataframe.
Debugging Python syntax errors, indentation, and logic flows.

# What I struggled on
Managing session state bugs where choices would make the player reset to the first scene
Correctly setting up boolean and string checks inside streamlit button columns without breaking the quiz progreesion.
Learning about session state for the first time was new and little confusing but after a while you get used to it.
